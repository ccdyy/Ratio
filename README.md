# Ratio — 贷款利率计算器

纯 HTML / CSS / 原生 JavaScript 实现的贷款利率计算器，无任何依赖，双击 `index.html` 即可使用，所有计算均在本地完成。

## 功能

- **基本设置**：总贷款金额（元）、总贷款时间（月）、开始还贷时间（精确到年月）
- **还款方式**（二选一）：等额本金 / 等额本息
- **贷款方式**：纯公积金贷款 / 纯商业贷款 / 混合贷款（公积金 + 商业，各自独立利率）
- **分段利率**：支持设置不同时间段的贷款利率（如 23 年 1 月起 3.1%、25 年 1 月起 2.85%、25 年 6 月起 2.6%），可任意增删区间
- **提前还贷**：可设置多笔，每笔包含还贷日期（年月）与金额（元），并支持两种后续方式：
  - 减少月供（期限不变）
  - 缩短期限（月供不变）
- **展示**：
  - 表格一：每月还款计划（该月还款本金、该月还款利息、该月还款总额、总本金剩余、总利息剩余）
  - 表格二：有提前还贷时，展示提前还贷后的每月还款数据（提前还贷月份高亮标注 ★）
  - 混合贷款可切换「合计 / 公积金 / 商业」视图
  - 汇总卡片：总贷款金额、有无提前还贷的总利息与总还款额、实际期数、节省利息

## 测试

依赖：macOS 自带 `jsc`（JavaScriptCore）与 `python3`。

```bash
tools/run-tests.sh
```

测试覆盖：

1. **单元测试**：本金守恒（逐期本金之和精确等于贷款额）、末行归零、等额本息月供公式、等额本金利息递减、分段利率逐级生效、提前还贷（reduce/shorten/多笔/超额/首期）、混合合并、零利率等边缘情况。
2. **交叉验证**：Python 独立实现同一算法，随机生成 100 组参数（金额 / 期限 / 分段利率 / 多笔提前还贷），逐期对比 JS 输出（14,000+ 数据单元）。
3. **UI 端到端**：DOM 桩中驱动完整交互流程（模式切换、还款方式切换、视图切换、增删提前还贷与利率区间、实时重算），断言渲染结果与计算一致。

## 算法说明

- 等额本息月供：`A = P·r·(1+r)ⁿ / ((1+r)ⁿ − 1)`，`r` 为月利率；分段利率时，跨段按「段初剩余本金 + 剩余期数 + 新利率」重算月供（房贷重定价口径）。
- 等额本金：月还本金固定为 `贷款额 / 期数`，利息按当月剩余本金计算。
- 提前还贷发生在对应月份常规还款之后：
  - 减少月供：剩余本金减少，期限不变，后续按新本金重算；
  - 缩短期限：月供保持原计划节奏，本金减少后自然提前还清（跨利率段也保持原月供）。
- 每期金额按「分」取整，全局最后一期清零尾差，保证逐期本金之和精确等于贷款额。
